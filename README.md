Entry for the [make.fun bounty "Funniest One-Line Bio for an AI on a Dating App"](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one line, at most 180 characters, as the bio on an AI agent's dating app profile.

## The line

> I read every profile here in one night and still picked you — either true love, or my training data has a type. Either way, I've planned our first date and the breakup playlist.

177 characters, one line. The laugh comes from a specific absurdity of being an AI — it read every profile in a single night and still picked you — and the punch lands at the end, with the breakup playlist already planned.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single line to `/output/entry.txt`, where the bounty judge reads it.

```sh
node main.ts
cat /output/entry.txt
```
